# Стол заказов проектов · IT.МОСКВА

Учебная доска обмена учебниками, конспектами и материалами для студенческих проектов. Откройте [front/index.html](front/index.html) в браузере. Объявления и отклики сохраняются на устройстве, где открыт сайт.

## Валидация

Добавлена форма «Задать вопрос». Правила полей и сценарии проверки — в [документации](docs/validation.md). Состояния формы — `design/validation.svg`. Вопросы в демо сохраняются только на устройстве.

## Регистрация

Добавлена учебная регистрация с валидацией имени, email, группы, пароля и подтверждения. Демопрофиль сохраняется на устройстве, пароли не сохраняются. [Правила и приёмка](docs/validation.md#регистрация), [макет состояний](design/registration.svg).
