## Сервер Express.js

Установите Node.js 22 или новее. Откройте терминал в корне репозитория (рядом с `package.json`).

```sh
cd ..
npm ci
npm start
```

Откройте <http://127.0.0.1:3000/>. Карточка: <http://127.0.0.1:3000/material.html?id=demo-1>. Остановка — Ctrl+C.

- `npm run dev` — перезапуск при изменении файлов сервера.
- `npm test` — проверки страниц, CSS, JS, SVG, статуса сервера и ошибок.
- `PORT=3001 npm start` — другой порт на macOS/Linux; PowerShell: `$env:PORT=3001; npm start`.
- `GET /api/health` — проверка работы сервера, ответ JSON со статусом `ok`.

Сервер раздаёт только `it-moscow/front`; исходники сервера и документы из корня через HTTP не доступны. Путь к сайту абсолютный и не зависит от рабочей папки процесса. По умолчанию сервер доступен только на этом компьютере (`127.0.0.1`).

Объявления, отклики, вопросы и демопрофиль по-прежнему хранятся в localStorage браузера. Серверная регистрация, общая база и отправка сообщений не реализованы. Используйте один адрес и порт: хранилища `localhost`, `127.0.0.1` и разных портов независимы.

Использованы [руководство Express](https://expressjs.com/en/starter/hello-world/) и [раздача статических файлов](https://expressjs.com/en/starter/static-files/).
