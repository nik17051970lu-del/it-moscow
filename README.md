## Валидация

Добавлена форма «Задать вопрос». Правила полей и сценарии проверки — в [документации](it-moscow/docs/validation.md). Состояния формы — [`it-moscow/design/validation.svg`](it-moscow/design/validation.svg). Вопросы в демо сохраняются только на устройстве.

## Регистрация

Добавлена учебная регистрация с валидацией имени, email, группы, пароля и подтверждения. Демопрофиль сохраняется на устройстве, пароли не сохраняются. [Правила и приёмка](it-moscow/docs/validation.md#регистрация), [макет состояний](it-moscow/design/registration.svg).
