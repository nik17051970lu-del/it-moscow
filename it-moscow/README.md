## Обновление 23.11.2026

Название проекта: **Стол заказов проектов · IT.МОСКВА**. Обмен учебными книгами, конспектами и материалами внутри колледжа.

Стили подключены из `front/styles/main.css`, изображения — локальные SVG из `front/assets/`. Для согласованного хранения между страницами запускайте сайт через HTTP: `python3 -m http.server 8000` из папки `front`, затем откройте <http://localhost:8000>. GitHub показывает исходники HTML, а не работающий сайт.

В localStorage сохраняются объявления, отклики, вопросы, демопрофиль, фильтры каталога и черновик объявления. После публикации черновик очищается. Пароли не сохраняются. Очистка данных браузера удаляет локальные записи; другой браузер их не увидит.

Адаптив: 3/2/1 колонки, узкие экраны от 320 px, переносы длинного текста, прокрутка диалогов по доступной высоте. Иллюстрации категорий не являются фотографиями реальных товаров.
