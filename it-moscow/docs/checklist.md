## Выполнено

- Подключены общие стили на главной странице и странице материала.
- Добавлены локальные SVG-иллюстрации книг, конспектов и материалов; изображения подключены в каталог и подробности.

## Проверено

- Относительные ссылки на HTML, CSS, JS и изображения ведут к существующим файлам.
- Три JavaScript-файла проходят синтаксическую проверку.
- Проверка логики черновика: ввод → сохранение → восстановление.
- В Microsoft Edge через локальный HTTP-сервер открыта карточка материала: стили и SVG отображаются, содержание загружается.

Запуск из папки front: `python3 -m http.server 8000`, адрес `http://localhost:8000/`. Все страницы должны открываться с одним адресом и портом, чтобы использовать общее хранилище. Для file:// поведение хранилища между страницами зависит от браузера.

Текущая проверка не является подтверждением прохождения всей мобильной матрицы. Сайт остаётся локальным демо без серверной отправки данных.
